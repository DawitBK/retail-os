# Enterprise bar: Retail OS scorecard

**DONE** means there is code and a test (the evidence column says where), **PARTIAL** means part
of it exists, **TODO** means it does not exist yet. The status is deliberately honest.

Status as of 2026-10-29 (web app and API: identity, catalogue, parties, purchasing, sales, returns, damage, stock counts, accounting, alerts, dashboard, analytics, forecasting, import, demo data).
